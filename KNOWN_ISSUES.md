# Known issues

Project-local notes for Frontier Explorer. SEV live-demo / Jetson details live under [`sim-sev/KNOWN_ISSUES.md`](sim-sev/KNOWN_ISSUES.md).

## Offboard before Explorer

Starting the Explorer program before selecting offboard mode (`o`) after takeoff crashes the program. See `sim-sev/KNOWN_ISSUES.md` for the full sequence and which demo scripts enforce it.
